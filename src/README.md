# Diffusion Policy — source package

See the [root README](../README.md) for full documentation: setup, folder structure, run commands, and file-by-file reference.

This package (`diffusion_policy`) contains the architecture modules (UNet, PlainConv, evaluation utilities) adapted from ["Diffusion Policy: Visuomotor Policy Learning via Action Diffusion"](https://arxiv.org/abs/2303.04137v4) and the [original Stanford implementation](https://github.com/real-stanford/diffusion_policy).
